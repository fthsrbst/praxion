# Praxion

**Agents that learn games by playing them, and write their own skills along the way.**

Praxion is an autonomous game-playing system. Instead of relying on a large model for every
move, it turns what it learns into reusable, verified skills: code it writes, tests and keeps
in a growing library. The more it plays, the less it needs to think from scratch.

The first demonstration targets Minecraft. The core is being designed to be game-agnostic,
so that new games plug in without rewriting the agent.

> *Praxis*: learning through practice.

## Status

Research phase. No architecture or code has been committed yet. Findings are collected in
